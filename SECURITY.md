# Security policy

## Supported versions

Only the latest release gets security fixes. Update to the newest version from the [Releases page](https://github.com/Nexvyn/hushio/releases/latest) before you report.

## Report a vulnerability

Report it privately with the [private report form](https://github.com/Nexvyn/hushio/security/advisories/new) in this repository's Security tab. Please don't open a public issue for a security problem.

Include:

- the Hushio version and your platform
- what an attacker could do, and what they need first
- steps or a small proof of concept that shows the problem

The maintainers aim to reply within 7 days. Once a fix ships, the advisory is published with credit to you, unless you ask to stay anonymous.

## What counts

Examples of problems worth reporting:

- a way to read or change Hushio's stored sign-in tokens or your data from another app or website
- a crafted link, playlist, file or lyrics response that runs code or reads files
- a way to make an update install something the maintainers did not sign
